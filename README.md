# WISH SWING Dashboard

Generated public page only. Rebuilt daily at 08:30 IST by
`StockScreener/publish_pages.py --push` in the private workspace.

The dashboard combines Double Bottom, Bull Flag and Ascending Triangle with one
auditable micro/macro quality score and Qualified / Best Qualified entry tiers.
It also reports and filters the consecutive completed trading sessions in each
stock's current green, amber or red moving-average trend.
Each stock popup links directly to its Screener.in page and, when Zerodha's
public NSE instrument list has a matching token, its Kite chart.

Source code and raw data are NOT in this repository.
